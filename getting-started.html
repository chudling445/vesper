⌂

LOCAL · PRIVATE

Use a model on your PC

  1. 1

    Install Ollama for Windows, then open Ollama.

  2. 2

    Open Ollama and download a chat model that fits your computer.

  3. 3

    Return to Vesper, open LLM Settings, choose Ollama · local, tap an installed model name, then choose Save Model.

Your chat stays on this computer when you use Ollama.

✦

ONLINE · HOSTED MODEL

Connect an online provider

  1. 1

    Open LLM Settings and choose a provider.

  2. 2

    Add the provider’s API key to the private .env file beside Vesper, then restart.

  3. 3

    Select a model, choose Save Model, and start chatting. Your messages go to that provider.

Never paste API keys into the chat. Keep .env private, and review your provider’s privacy and billing terms.

Open Chess in the conversation header. Choose your side, pick a style, and play privately without a model connection.
